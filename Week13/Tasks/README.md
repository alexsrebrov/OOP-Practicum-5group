# Задача 1

Имплементирайте конзолен калкулатор:
 - **add** *num1* *num2* `num1 + num2` 
 - **sub** *num1* *num2* `num1 - num2`
 - **mul** *num1* *num2* `num1 * num2`
 - **div** *num1* *num2* `num1 / num2`
 - **pow** *num1* *num2* `num1 ^ num2`
 - **exp** *num* `e ^ num`

**Изисквания**:
 - Хвърляйте подходящо ваше изключение, когато:
    - командата е невалидна
    - има грешен номер на аргументи
 - Хвърляйте подходящо стандартно изключение, когато:
    - вместо число се подава низ
    - деление на 0
 - Използвайте ламбди за пресмятане вместо да правите отделни функции
 - Резултатът трябва да е 
    - "Result: \<result>" при правилни данни
    - "Error: \<message>" при невалидни данни или грешка

Можете да използвате `<sstream>`

Примере вход и изход:
```c++ 
add 2 3         // 5
div 10 0        // Error: division by zero
pow 2 3         // 8
hello 1 2       // Error: invalid command
add 5 x         // Error: invalid argument
```
